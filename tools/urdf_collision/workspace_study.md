不强制整个可用空间收缩到一张曲面；下式只是经过本轮检查的两条**建议姿态分支**：

```text
s = q2 + q3
u = clamp((s - 90)/40, 0, 1)
H(u) = 10*u^3 - 15*u^4 + 6*u^5
q4_ref = branch * 160 * H(u)       branch ∈ {-1,+1}
q5_ref = 20 * H(u)
```

也就是 `s≤90°` 时参考腕部为 0；`90°<s<130°` 时提前平滑转腕；
`s≥130°` 时参考 J4=−160° 或 +160°、J5=20°。位置及前两阶导数在分段连接处连续。
该“角度之和”规律是当前记录域和当前模型下试验得到的简化调度，不是任意机构的碰撞定律。
若用户指定的腕姿态本来满足条件集合，应保留它，不必强制改成上述参考。

分支须沿已检查的连通路径选择，不能在危险区直接切换。在 J2/J3 原记录上限各内缩 1°、
J5=20° 时，J4 从 −160° 直接转到 +160°，641 个 0.5° 检查点中有 529 个碰撞。
应沿已检查路径退回可换支姿态后再切换；本轮两个分支都回到软件全零参考，能在该参考衔接。
任意现有姿态如何接入参考曲线，仍需另做路径检查，不能把函数直接当作电机即时位置命令。

## 整块联合区域与可查询分段公式

### 公式与运动含义

把已经整块通过检查的四轴角度盒记为：

```text
B_k = [a2k,b2k] × [a3k,b3k] × [a4k,b4k] × [a5k,b5k]

I5(q2,q3,q4) =
  ∪ { [a5k,b5k] :
       a2k≤q2≤b2k，a3k≤q3≤b3k，a4k≤q4≤b4k }

允许：q1=0，q5∈I5(q2,q3,q4)。
```

这是分段集合关系，不强迫腕部始终跟随一条参考曲线。
每块盒内部允许四轴任意组合和异步变化；不同盒之间仍需检查完整联合轨迹是否始终处于盒并集。
`segment_in_regions` 解析求直线关节路径与所有盒的参数区间交集，只有这些区间无缝覆盖 `[0,1]` 才通过。
五次时间律若四轴共享同一个进度参数，其几何轨迹仍是该关节直线；
分轴错峰或跨盒混合曲线不能直接沿用一条直线的检查结果。
没有使用每轴独立裁剪来修改已规划的联合路径，也不对 J4 连续角取模。

### 整块数值检查，不把样本当区域

先对只依赖单关节的 30 个相邻零件对在对应完整记录域内自适应细分。
只在该轴已验证的区间内，才可将该组约束从后续四维细分中分离；仍保留全部非相邻零件对和地面约束。
这些检查在本次实际加载的同一模型中完成，不直接信任缺少文件身份信息的历史通过报告。

对每个盒中心 `qc`、半宽 `h`，利用现有半径界验证：

```text
d_i(qc) > Σ_j 2 r_ij sin(min(|h_j|,π)/2) + ε
ε = 10^-6 m；h 使用弧度。
```

满足的约束在子盒中继续成立；未满足则细分。
这只是在当前 FCL 网格距离及浮点算术下的保守数值内近似，不是形式化区间算术证书；
`ε` 是浮点保护，不是实物防碰撞余量。
一个盒中心碰撞，只记录该点的碰撞见证，不能宣布整块盒都碰撞。
预算或分辨率不足的部分保留为“未证明”，不写入允许表，也不称为真实不可达区。
保留记录外边界；未验证部分是本轮内近似的覆盖缺口，不是另设新的实机限位。

### 首轮失败记录与依赖分组

原映射和候选映射的首轮完整四维搜索各执行 30,000 个节点，均未得到整块通过的盒。
原始失败/未证明结果完整保存在 `build/workspace_regions_20261117_{baseline,alignment}_v1/regions.json`，
没有删除或改写成通过。首轮各有 30,001 块待证明区域，没有因此宣称“运动空间为零”。
主要瓶颈是每块都尚未证明 `part1/part2`、`part1/part3`、`part1/part4`、`part1/part5`；
前两对仅依赖 J4/J5，后两对仅依赖 J3/J4/J5，粗四维铺网重复细分了无关的肩肘维度。

后续实现按约束真正依赖的关节组分别细分，再取交集：

```text
G_g = ∪k B_gk
Ω = 记录域 ∩ 相邻装配已验证域 ∩ ⋂g G_g

I5(q2,q3,q4) =
  相邻装配允许的 J5 区间
  ∩ ⋂g ( ∪ { B_gk 的 J5 区间：q2,q3,q4 满足 B_gk 的相应范围 } )
```

不依赖的轴按整个适用域抬升，不是把它们锁在零点。
全部 89 个原几何约束必须被相邻检查或某一组覆盖，组与组之间必须取**交集**，不能取并集。
这是前述统一盒并集的等价分解表示，避免实际展开所有组合。
区间只在其他维度完全相同且确实相接/重叠时合并，绝不填补区间空洞。
每组完整通过时可用一块适用域表示；未完整通过时仍保留分段表和未证明部分。
在公式中，整个适用域已经通过的组就是恒等条件，可省略显示，但保留验证记录；
因此没有必要把几十个几何对逐一暴露为用户的操作限位。

分组结果中的总覆盖率通过固定种子的随机点估计，明确不同于第一轮整盒分割的精确测度比例；
