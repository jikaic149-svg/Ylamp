# Ylamp 五轴仿真限位公式｜已验证版

依据 2026-11-17 已完成的验证。仅用于当前 URDF / MuJoCo 模型的离线仿真，不用于实机下发。

## 放行规则

设 `q = (q1,q2,q3,q4,q5)` 为软件角，单位为度。名义 `q1 = 0`，`q4` 是连续角，不折回到 ±180°。共同包围域 `D` 为：

| 轴 | 软件角外边界（°） |
| --- | --- |
| J1 | 0 |
| J2 | `[-36.02019137988516, 45.92141062011484]` |
| J3 | `[-97.19978309762811, 104.86764790237187]` |
| J4 | `[-227.3995985, 227.39959850000002]` |
| J5 | `[-16.609607075805666, 22.632856000000004]` |

`D` 只是必要条件，不能把表内的角度任意组合。**固定 J2、J4、J5 后，J3 的限位是一个或多个闭区间：**

```text
I3(q2,q4,q5) = (I表,baseline ∪ I分离,baseline) ∩ (I表,alignment ∪ I分离,alignment)
放行(q)      = (q ∈ D) 且 (q3 ∈ I3(q2,q4,q5))
```

- `I表` 是对应映射的原已验证区间（v10 全表及原扩展，包含 75 个共同验证盒）。`I分离` 是对应映射下由末端分离条件扩展出来、已通过整段校验的 J3 区间。两种映射是原映射和 J5 零点偏移的敏感性副本，后者不是实测标定。
- 分离条件：在各自映射下，末端 `part1` 到地面的间隙大于 `δ`，且对底座的 `part6/7/8/9`，每对网格都能找到一个方向，使两组原网格顶点的投影区间相隔大于 `δ`（各对可用不同方向）。`δ = 0.000001 m` 只是仿真数值阈值，不是实机安全间隙。在 `D` 内其余 84 项约束沿用既有整域校验。
- **结果为空或落在区间空档就不放行。** 未证明的区间不能补齐；不能用相邻查询结果插值，也不能把多段区间合并成总最小值到总最大值。姿态放行不等于运动放行，换目标要另查完整路径；保留原仿真回放的 1° 命令内缩。

## 查询示例

固定 `J2=27.363787522718127°`、`J4=-60.76971657601524°`、`J5=17.853385365324336°`，两种映射共同允许的 **J3 = `[-97.19978309762811°, 102.845000277616°]`**。相对此姿态的原表上限 `92.23843346487187°`，增加约 `10.61°`。`102.845°` 不是其他姿态的通用上限，也不代表此切片已求到最大。

从项目 `code` 目录执行（第三个角度是被扫描的 J3 占位值；输出目录须尚不存在）：

```powershell
& 'D:\python\venvs\ylamp-sim\Scripts\python.exe' tools/urdf_collision/workspace_envelope.py query `
  --extension build/workspace_frontier_balanced_all_20261117_v1 `
  --software 0 27.363787522718127 0 -60.76971657601524 17.853385365324336 `
  --seconds 3 --out build/workspace_support_query_handoff
```

读取输出 `envelope_query.json` 中的 `commonJ3IntervalsDeg`；上文数值以[已保存的查询结果](../../build/workspace_support_query_20261117_v2/envelope_query.json)为准。换姿态时替换 J2、J4、J5，不要直接沿用示例 J3 限位。

## 验证记录

- [仿真结果审计](../../build/workspace_support_result_audit_20261117_v2/result_audit.json)：6 条新增闭环路线，两种映射共 36 个名义段通过；两档速度、两种映射合计 24 个新增工况及 24 个对照工况全部通过。4,654 个仿真状态／插值点的独立 FCL 复查未检出碰撞。
- [跟踪误差审计](../../build/workspace_tracking_tube_result_audit_20261117_v1/result_audit.json)：上述 6 条路线的 36 段均通过 89 项约束的连续校验，覆盖 24 个新增工况的 2,864 个保存状态及 2,840 条线性插值边。向内舍入的 J1–J5 逐轴误差上界为 `(0.00010, 0.04823, 0.00458, 0.00995, 0.00170)°`，仅是这 6 条路线的仿真假设，不扩大名义 `J1=0` 的限位域。
